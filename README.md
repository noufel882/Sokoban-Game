# Sokoban

A simple Sokoban puzzle game made with **GameMaker Studio 2**.

## About

Sokoban is a puzzle game where the player pushes boxes onto designated target locations.

The player must plan their moves carefully, since boxes cannot be pulled.

## Controls

* `↑` — Move Up
* `↓` — Move Down
* `←` — Move Left
* `→` — Move Right

## Goal

Push all the boxes onto the target locations to complete the level.

## Built With

* GameMaker Studio 2
* GML (GameMaker Language)

## Project

This project was created as a learning project to practice game development and programming with GameMaker.
